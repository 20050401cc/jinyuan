# 烬渊

原创的俯视角地牢肉鸽射击游戏。纯 HTML5 Canvas + 原生 JavaScript，无依赖、不联网，所有画面、音效和音乐都由代码实时生成。

## 怎么玩

- **Windows 桌面版**：运行 `desktop/dist/Jinyuan-win32-x64/Jinyuan.exe`（打包方法和 Steam 上架见 [STEAM.md](STEAM.md)）。

- **开始界面**：先选「电脑端」或「手机端」，下方会显示对应的操作方式，再点「开始远征」；暂停菜单里也能切换。
- **本机**：双击 `烬渊.html`（或 `index.html`），用 Chrome / Edge / Firefox 打开。
- **发给别的设备**：只需要 `烬渊.html` 这一个文件。它把全部代码打包在了一起，不依赖 `src/` 文件夹，也不需要网络。用微信、QQ、U 盘、网盘传过去，在对方设备的浏览器里打开即可。
- **手机 / 平板**：支持触屏，请横屏。安卓上用文件管理器选择"用浏览器打开"；iPhone / iPad 的"文件"App 预览不能运行游戏，需要用能打开本地网页的浏览器或 App。

目标：向下穿过三层地牢，每层击败一位守护者，最后熄灭「烬渊之心」。

### 难度

开始界面「开始远征」上方选择，存档会记住这局的难度。

| 难度 | 敌人血量 | 敌人伤害 | 敌弹速度 | 其它 |
| --- | --- | --- | --- | --- |
| 简单（默认） | ×0.65（守护者 ×0.7） | ×0.55 | ×0.85 | 生命上限 +25、金币 +30%、护盾恢复更早、每波敌人更少 |
| 困难 | ×1 | ×1 | ×1 | 1.3.0 及以前的原版数值 |
| 噩梦 | ×1.4（守护者 ×1.35） | ×1.35 | ×1.1 | 每波敌人更多、护盾恢复更晚 |
| 地狱 | ×1.85（守护者 ×1.7） | ×1.7 | ×1.2 | 生命上限 −20、金币 −10%、敌人最多、护盾恢复最慢 |

### 剧情

你是深渊边上小镇的孩子。七年前，最后一位守灯人——你的母亲——提着灯走进渊火，再也没有回来；今年渊火又开始翻涌，你带上她留下的旧灯往下走。剧情分为序章、两段层间幕间和终章，配有全程序绘制的过场插画；三位守护者登场时有电影式开场和阶段台词。

- 「设置 → 剧情过场」可选**仅首次**（默认，看过的章节不再自动播放）、**每次**或**关闭**。
- 过场中点击 / 空格 / 手柄 A 继续，Esc / 手柄 B 按两次跳过。
- 看过的章节可以在主菜单右上角「剧情」里随时重看。

### 语言

支持**简体中文、繁體中文、English、日本語**。首次打开按系统语言自动选择，之后可在主菜单右上角的语言按钮或「设置 → 语言」切换。

### 设置与成就

主菜单右上角是「语言」「剧情」「成就」和「设置」，暂停菜单里也能进设置。设置包括语言、剧情过场、操作方式、主音量 / 音效 / 音乐、全屏、画面清晰度、屏幕震动、伤害数字、手柄震动、帧率显示。共 16 个成就，解锁时右上角会弹出提示。

### 体感操控（手机端可选）

在开始界面选「手机端」后，点「体感操控」开关开启（暂停菜单里也能开关）：

- **倾斜设备**移动角色，倾得越多走得越快；左半屏摇杆仍然可用，拖动时优先生效。
- **甩动设备**触发闪避。
- 以开始游戏时的握持姿势为中立位；姿势变了的话，暂停再继续就会重新校准。
- 浏览器只允许 **HTTPS 网址** 读取传感器，所以体感只在线上网址里可用，直接打开本地 `烬渊.html` 文件时会提示不支持。iPhone / iPad 首次开启会弹出权限询问，需要点允许。

## 存档

- 远征进度会**自动保存**在浏览器里（每两秒一次，暂停、切到后台、关闭页面时也会存）。刷新或关掉再打开，主菜单会出现「继续远征 · 第 N 层」。
- 存的内容：层数、地图和已探索/已清空的房间、生命和能量、两把武器、增益、金币、地上的物品。
- **战斗中不存档**：在锁门的房间或 Boss 战里刷新，会回到进这个房间之前的状态。
- 死亡或通关后存档清除；点「新的远征」会覆盖当前存档。
- 设备选择、声音和音乐开关、战绩（远征次数、通关次数、最深层数）也会记住。
- 存档跟着浏览器和网址走：换设备、换浏览器、清除浏览器数据或用无痕模式，都不会带上存档；线上网址和本地 `烬渊.html` 的存档也互不相通。

## 规则速览

- **三条资源**：生命；护盾（几秒不受伤后自动回满，先于生命承伤）；能量（大多数武器开火消耗，靠掉落的蓝色能量晶体补充，也会极慢地自然回复）。
- **房间**：走进战斗房会锁门，清完所有波次才开门。小地图（右上）显示已探索的房间：灰=战斗、金=宝箱、绿=商店、红=Boss。
- **武器（8 种）**：火花手枪、碎岩霰弹、蜂群速射、棱镜光束、回响弹球、烬刃（近战，可斩碎子弹）、裂空榴弹、追光弩。最多带两把，再捡会替换手上那把。
- **敌人（7 种）**：扑咬兽（冲撞）、灯芯射手（点射）、孢子炮台（环形散射）、爆燃虫（自爆）、巢母（召唤幼体）、幼体、凝视者（预警后狙击）。
- **Boss（3 个）**：熔炉守卫、虚空织者、烬渊之心，各有三个阶段的弹幕。
- **成长**：击败每层 Boss 后进入传送门，从 3 个随机增益里选 1 个（共 24 种）；金币可在商店买药剂、电池、武器和额外增益。
- **机制型增益（带「机制」角标）**：灼烧弹头、余烬爆裂（燃烧的敌人死亡时爆炸并传火）、连锁电弧、寒霜弹头（减速并易伤）、血之契约（残血增伤）、残光剑气（近战发射剑气、斩弹回能）、影袭（闪避后必定暴击），可以互相联动组成流派。
- **增益来源**：开局「启程之礼」三选一；每层有一间**精英房**（小地图金框，最后一波有一只强化精英），清完再三选一；守护者之后三选一；商店也能买。一局通常能拿到 7～10 项。抽取会按当前构筑加权（例如有灼烧时更容易出余烬爆裂，有烬刃时更容易出残光剑气）。
- **武器进化**：持有基础武器并集齐配方里的两项增益后，下一次增益选择会出现进化选项。暂停界面左侧会显示配方进度。
  - 碎岩霰弹 + 灼烧弹头 + 余烬爆裂 → **炼狱龙息**
  - 棱镜光束 + 连锁电弧 + 节能回路 → **天罚棱镜**
  - 烬刃 + 残光剑气 + 影袭 → **断渊之刃**
  - 追光弩 + 寒霜弹头 + 穿甲弹头 → **永冻之矢**
- **武器对比**：靠近武器时显示和将被替换那把的 DPS（含分裂弹仓、暴击期望、血之契约）与每秒耗能；先按 Q 选好要替换的槽位。
- **跑图**：脱战时移动速度 +25%；展开地图里点击已探索的安全房间可直接传送。
- **新手节奏**：第 1 层前两间战斗房怪物更少，第一间只有一波。
- **音乐**：每层一个调，探索时舒缓，进入战斗加入鼓点，Boss 战节奏加快。

## 文件结构

```
烬渊.html         打包好的单文件版本（由 build.py 生成，可单独分发）
index.html        开发用入口页面，按顺序加载 src/ 下的脚本
build.py          把 index.html、src/ 和内嵌字体合并成 烬渊.html：python build.py
STEAM.md          Steam 上架交付说明
assets/fonts/     内嵌字体（思源黑体、马善政楷书、霞鹜文楷裁剪版，SIL OFL 1.1；霞鹜文楷用于繁体和日文标题，裁剪后改名 JY Kai）及授权
desktop/          Windows 桌面版（Electron）：main.js 主进程、preload.js、pack.js 打包脚本
steam/            商店图形、截图、成就图标与清单、SteamPipe 上传模板
tools/fonts.py    按游戏用字裁剪字体（改了文字或译文后要重新运行）
tools/i18n.py     多语言：检查译文覆盖率（check）、用 OpenCC 生成繁体中文表（zht）
tools/art.py      渲染商店图形、程序图标和成就图标（配合 tools/art.js）
src/core.js       命名空间、数学工具、键鼠输入
src/i18n.js       多语言引擎（以简体中文原文为键）、字体、按语言换行
src/lang_*.js     English / 日本語 / 繁體中文 译文表
src/audio.js      Web Audio 合成音效与生成式背景音乐
src/touch.js      触屏虚拟摇杆与按钮
src/motion.js     体感操控：倾斜移动（方向传感器）、甩动闪避（加速度计）
src/dungeon.js    随机地牢生成、瓦片碰撞、房间锁门与刷怪波次
src/gfx.js        主题配色、程序生成的砖石瓦片与贴花、火把、动态光照
src/bullets.js    子弹、爆炸、粒子、飘字、金币/能量/生命掉落
src/weapons.js    武器数据、开火逻辑、武器外形绘制
src/player.js     玩家移动/闪避/资源、受伤、互动（拾取、宝箱、商店、传送门）
src/enemies.js    普通敌人的数据与 AI
src/bosses.js     三个 Boss 的阶段与弹幕招式
src/sprites.js    玩家、敌人、Boss 的造型与动画
src/perks.js      增益列表、增益选择、商店货架
src/save.js       自动存档与读档、战绩（浏览器本地存储）
src/settings.js   设置项、自适应分辨率与全屏、设置界面
src/pad.js        手柄输入、菜单焦点导航（手柄 / 键盘）、震动
src/achievements.js 成就定义、解锁提示、成就界面、Steam 同步接口
src/story.js      剧情文本、守护者台词，以及全部过场插画（程序绘制）
src/cutscene.js   剧情播放器、剧情回顾、守护者登场、阶段台词、楼层标题卡、转场
src/render.js     世界渲染（物品、子弹、发光层、特效、氛围）
src/ui.js         HUD、小地图、主菜单、暂停、增益选择、结算画面
src/main.js       游戏状态机、换层、主循环
```

改了 `src/` 里的代码后，运行一次 `python build.py` 重新生成 `烬渊.html`。

加新文字时：界面文字直接写中文原文（`G.text` 会自动翻译；拼接的句子用 `G.tf('第 {0} 层', n)` 模板），然后在 `src/lang_en.js`、`src/lang_ja.js` 里补译文，运行 `python tools/i18n.py zht` 生成繁体、`python tools/i18n.py check` 检查是否漏译，最后 `python tools/fonts.py <思源黑体.ttf> <马善政.ttf> <霞鹜文楷 Medium.ttf>` 重新裁剪字体。

想调数值：武器在 `src/weapons.js` 的 `G.WEAPONS`，敌人在 `src/enemies.js` 的 `G.ENEMIES`，Boss 血量和招式在 `src/bosses.js`，玩家初始属性在 `src/player.js` 的 `G.createPlayer`，音效和音乐在 `src/audio.js`。
